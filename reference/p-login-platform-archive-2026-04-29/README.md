# P-Login / Music Platform Archive

This archive contains the retired music platform implementation that used to live in the active app tree.

Archived on 2026-04-29 to keep the current desktop runtime from loading the platform pack contract registry,
builtin platform pack artifacts, p-login UI, and builtin provider sidecars during the upcoming performance
optimization work.

The original paths are preserved under this directory so the implementation can be compared or restored during
the later refactor.
